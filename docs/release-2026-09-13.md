```bash
git switch main
git pull --ff-only origin main
npm ci
npx wrangler secret put BOOTSTRAP_SECRET --config wrangler.jsonc

```

初始化密钥至少 16 个字符，不是登录密码，不要写进 Git。部署前配置 `CLOUDFLARE_ACCOUNT_ID` 和 `CLOUDFLARE_API_TOKEN`，并确认 `wrangler.jsonc` 指向工资系统专用的 Worker、D1 和 R2。
