# 工资审批表格版试用

本分支 `ui/review-table-preview` 从 `origin/main` 的 `13de985` 创建。只供本地试用，未合并到 main，未部署线上。不要直接按正式部署流程发布此分支。

## 怎么使用

进入「工资审核 → 工资审批」。账号、工作月份、状态、待分配筛选和分币种统计保持原有规则。

表格从左到右为员工姓名、金额与币种、状态、日期、工作内容、部门、负责人、指定审核员、提交时间、详情及固定操作列。横向滑动仅发生在表格内部，手机也保持表格形式。已通过行浅绿，驳回状态红色；所有状态仍保留文字，JPY/CNY 不相加。

- 「展开详情」在该工资行下方显示完整工作内容、计费、单价、数量、工时、休息、交通、备注、附件入口及审批历史。展开区重复标出员工、日期和金额。
- 「展开全部详情／收起全部详情」只作用于当前页，每页 20 条。切换账号、月份、状态或页码会收起详情。全部展开不会预取或打开附件。
- 「弹窗查看」保留原有明细与审批记录弹窗。管理员的转交及已通过工资作废入口移到该行展开详情底部；其权限、校验和审计逻辑不变。
- 「通过」使用原审批接口。「驳回」先核对员工、金额、日期、工作内容和负责人，再填写理由。理由去除首尾空白后不能为空，最多 1,000 字符。取消、关闭和 Escape 不提交。
- 处理期间锁定操作。记录已被他人处理、转交或权限变更时，旧版本不能覆盖新结果；界面重新读取列表并提示核对。
- 没有保存提交历史时间的旧数据，提交时间显示「—」，不以创建或审批时间替代。

## 改动边界

后端唯一改动是在原权限范围内，读取每条申报最近一次提交历史时间并返回 `submittedAt`。未新增迁移、未改变审核员分配、权限、自审授权、计薪、币种、作废或审计规则。批准/驳回仍由原后端版本及权限检查决定。

当前预览使用独立 worktree、独立 D1/R2 本地目录和独立端口。main 工作目录、原本地数据库、3508 服务及线上数据库不参与本次测试。

浏览器实际检查：

- 管理员可见全部；指定审核员只见分配范围；普通角色额外授权账号只见获授权员工、可跨指定审核员审批；无权限员工没有审批入口，直接输入路由会返回首页，接口返回 403。
- 管理员通过与驳回、审核员通过、额外授权账号驳回成功；取消不改变条数和状态。双击通过只新增一条历史，相邻工资仍待审。
- 保持旧驳回弹窗打开，由另一请求先通过该记录：旧请求被拒绝，显示版本/状态提示并禁用再次确认，原通过结果保留。
- 20 条当前页全部展开；切页、筛选账号/状态/月度后收起。通过/驳回后列表及分币种统计更新，理由写入原审批历史。
- 320、390、768、1366 像素宽度及反复切换：页面没有被表格撑宽，操作列保持不透明固定位置，展开区宽度跟随表格视口。横滑后再调整宽度，页面仍保持正常。
- 长内容在普通行截断，详情完整显示；845 字符工作内容的手机驳回弹窗仍位于屏幕内，内容区域可滚动。原详情弹窗能够加载记录及附件入口。浏览器控制台未报告错误。

### 仍需试用确认

1. 真机 iPhone/Safari 的双指缩放、软键盘弹出及回缩手感尚未验证；本轮使用内置浏览器尺寸模拟和实际横向滚动，不等同于真机测试。
2. 附件接口的管理员、指定审核员、授权账号成功及无权限账号 403 已验证；但内置浏览器对 PDF 地址报告 `ERR_BLOCKED_BY_CLIENT`，未确认实际下载完成。请在常用浏览器中补验 PDF 查看/下载。
3. 每页 20 条、手机右侧上下排列按钮，以及展开详情后的信息密度，请先试用再决定是否合并。

## 可重复验证

只在新建的独立本地目录中执行，不使用现有数据目录。先 `npm ci`、迁移独立本地库、构建，再启动 `wrangler dev --local`。不要运行 remote migration、部署或清空脚本。

设置 `PAYROLL_TEST_BASE_URL`（localhost）、`PAYROLL_TEST_BOOTSTRAP_SECRET` 和 `PAYROLL_TEST_ADMIN_PASSWORD` 后：

```sh
npm run self-check:backend
npm run self-check:proxy
PAYROLL_TEST_SAVE_ACCOUNTS=1 npm run self-check:permissions
npm run self-check:void-travel
npm run self-check:reviewer-routing
npm run self-check:review-table
npm run self-check:review-table-api
```

最后一项会在该独立库中增加测试记录，并生成 `.local/review-table-preview.json`（试用账号及记录索引）。它拒绝远端地址以及与权限测试账号文件不匹配的地址。重复运行会新增测试数据，不清理既有记录。`.local` 中的密码和数据库不上传 Git。

本分支 GitHub CI 使用全新临时数据库运行上述检查，不接触线上服务。
