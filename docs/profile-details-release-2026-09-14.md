# 个人资料与工资详情修正（2026-09-14）

## 调整

- 本期工资申报四个状态表格中的“详情与审批记录”使用挂载到页面顶层的弹窗，不再受表格滚动容器限制。详情内容独立滚动，标题与关闭按钮固定；关闭后恢复焦点及页面滚动。
- 工资审批表格仍使用原有行内展开详情，审批及权限规则不变。
- 证件类型增加 My Number Card；My Number 番号推荐填写，可留空。管理员员工资料页能识别新证件类型。
- “银行卡/支付宝账户截图（需核对推荐上传）”改为选填，允许 0–2 个附件。不上传也可保存资料及提交工资；收款账号等原有必填资料保持不变。附件所有权、数量、格式及查看权限校验不变。
- 不涉及数据库迁移、数据清空或线上部署。既有附件和记录不会被删除。

## 重跑新增测试

```sh

# API 模式须先在同一独立本地数据库运行权限测试并保存其账号文件。
PAYROLL_TEST_BASE_URL=http://127.0.0.1:3514 npm run self-check:profile-details
```

API 测试仅接受 localhost/127.0.0.1，且要求测试账号文件中的地址一致。CI 已纳入静态与 API 两种模式。
