## 空数据库与账号

- 公开的 `/api/bootstrap-status` 只返回是否需要初始化以及固定账号名，不返回密码或其他数据。
- 空 D1 中首次调用注册 API 时，服务端忽略伪造的其他邮箱，固定创建 `TabitoAdimin01@tabitoedu.com` 的规范化值并授予管理员角色。同时，这次请求必须提交与服务端 `BOOTSTRAP_SECRET` 一致的初始化密钥。
- 服务端未配置至少 16 个字符的 `BOOTSTRAP_SECRET`，或请求缺失/提交错误密钥时，首个账号不会被创建。
- 仓库不包含生产默认初始化密钥或账号密码；首次部署者在 Cloudflare 配置加密 Secret，并在注册页自行设置账号密码。
- 后续注册账号只获得员工角色；新账号注册默认开放，管理员仍可用注册开关关闭。
- 登录成功、改密、会话签发/撤销和错误次数更新均使用带旧密码状态条件的 D1 原子批处理；回归会并发发起旧密码登录和管理员改密，确认改密后不会残留旧密码可用会话。用户自行改密会撤销全部旧会话并轮换当前会话令牌。
- 已登录的写请求同时校验 `Origin` 和 Fetch Metadata；同一主域下的其他子域不能借用会话发起附件上传、审批或登出。
- 所有新账号必须先提交中文姓名、现住址和多行联系方式。进入工资功能前还会逐项检查四位年份生日、身份证件类型、收款方式、银行卡正反面 1–2 个附件以及对应收款字段；页面常驻提示、页内错误和弹窗会列出确切缺项，直接请求业务 API 也会收到 428。
- 登录身份证件、资格外活动许可和抚养资料是选填，不参与工资功能门禁。

## 工资状态、部门和币种

```text
草稿(1) -> 员工提交 -> 待审核(2) -> 通过(3)
                                      -> 驳回(4)
```

- 新建/修改时服务端强制草稿状态，重算工时和金额，并清除伪造审核字段。
- 新申报只能选择有效的动态部门。服务端不信任客户端传入的部门名，而是从 D1 读取后写入 `departmentLabel` 快照。
- 停用部门不会删除或改写旧申报；停用后不能用于新申报。
- `currency` 只允许 `JPY` 或 `CNY`，数据表有单独币种列，JSON 业务快照也保留币种。
- 待审、通过和驳回在按工作日期的月份中继续可查；自检确认处理后两种状态都仍在审批数据中。
- 月度提交只把所选月份的草稿改为待审核，其他月份草稿保持未提交。回归同时提交了 21 条同月草稿，确认版本校验和审计写入均为原子操作。
- 审核员和管理员可为其他员工创建单条工资或固定排班批次，一次最多 62 条。最大批次及相同请求的幂等重放均已通过，失败批次不会留下部分记录。
- 批量排班可保存为按月定期规则。规则支持暂停、恢复、删除、按员工手动生成和定时分页生成；规则更新使用乐观锁，同一规则同一月份不会重复生成。
- 本系统按用户确认的运营规则允许管理员和审核员审批本人申报或自己代报的待审记录。工资所属人、创建人、提交人和审批人分别保存，可在付款前人工核对。
- 时薪项目使用员工填写的休息小时/分钟从总时长扣除；金额以实际分钟计算，不会因先四舍五入小数小时产生偏差。服务端拒绝休息时间超过总时长的请求，并确认长工时不会被自动扣除休息。
- 服务端拒绝不存在的工作日期、未来生日以及超过页面限制的资料/申报文本，不再静默截断输入。
- 新申报的负责人必须来自当前启用的工作负责人账号；服务端以账号 ID 解析权威姓名，拒绝伪造或已停用选项。旧申报保留当时的姓名快照。管理员可以移除最后一个负责人权限，系统不会静默恢复；重新授予前将无法新建申报。
- 07 总审计仅把状态 3 定义为已审批总支出，并将 JPY/CNY 分开返回；没有汇率时不相加。选择账号后，月度、年度和部门统计均排除其他员工记录。

## 附件、审计与会话

- R2 保存文件字节，D1 保存所有者、元数据和资料/银行/工资引用。
- 员工只能读取本人附件；审核员和管理员可读取员工全部附件，跨账号读取会写入 `file.read_privileged`。
- 附件仍被资料或工资引用时不能删除。
- 最近审计 API 对审核员/管理员最多返回 10 条。账号追踪同时匹配账号本人的操作、对账号的操作、其工资和其文件；显示时优先使用资料中的注册姓名。
- 月度工资汇总只对审核员/管理员开放，包含员工联系方式、收款资料、按币种已审批金额与全部 PDF 下载引用；自检确认员工账号无法读取，Excel 导出不包含附件内容。
- 会话是 24 小时 `HttpOnly` + `SameSite=Strict` Cookie，D1 只存会话令牌 SHA-256 摘要。
- 连续 5 次错误密码锁定 15 分钟；管理员重置密码可解除锁定并撤销旧会话，同时使用账号版本条件阻止并发重置互相静默覆盖。

## 运营边界

- 忘记密码邮件尚未接入邮件服务商；当前由管理员设置临时密码。
- 本系统记录资料、申报、审批和审计，不自动执行银行打款、税务申报或会计总账入账。
- 生产上线后需要由公司设定 D1/R2 备份、保留期、离职员工数据处理和管理员 MFA 规则。
