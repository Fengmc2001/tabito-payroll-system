# Logo 与未提交交通费回填

## 界面

左上角品牌区使用用户提供的 `public/tabito-logo-253970.png`，不裁切、不拉伸。侧栏底色与图片一致，移除原来的图标、文字和「工资申报」副标题。点击或使用键盘激活可返回首页，继续沿用原来的未保存内容离开确认。Logo 路径支持 `/payroll` 子目录。

## 交通费

过去只读取已提交记录，保存为未提交后再次新建不会出现刚填过的交通费。现在改为：

- 含交通费的工资只要保存成功，即可成为下次新建的默认交通起点、终点、金额，不必提交审核。
- 本人单条、管理员代报、批量保存都按工资所属员工记录；人民币和日元分别记忆。
- 取消勾选时仍按 `- / - / 0` 保存，不把未勾选的零费用当作新的默认值；明确勾选并填零则记住零。
- 当前表单手动改过的交通费，取消再勾选优先恢复该手动值。取消且未保存的表单、保存校验失败不会覆盖历史默认值。
- 删除的草稿、作废工资不再作为默认来源，回退到其余最近的有效保存历史。审批、驳回、转交、撤回等操作本身不覆盖默认值。
- 权限边界不变：本人读取本人的默认值，管理员代报读取对应员工的默认值；其他员工和审核员不能借此读取他人的草稿资料。

实现读取现有保存/提交历史，不使用审批时间排序；无历史的旧数据兼容读取当前记录。没有新增表、迁移或权限。

## 验证与发布范围

使用独立本地数据库及端口验证，不向现有试用库写入回归数据。新增 `self-check:travel-draft` 覆盖保存、修改、保存失败、零费用、删除回退、本人/代报/批量、账号及币种隔离；原分配、权限、作废、审批表格回归继续运行。`self-check:brand` 检查原图尺寸、资源路径和首页导航复用。

本轮只更新本地 3512 和 GitHub main，不部署线上，不执行任何重置或远端迁移。测试账号、数据库保存在被 Git 忽略的 `.local` 中。
